# ClimbFour

Four-bar live **pre-chorus climb** desk.

Your hook is finished. Your verse is finished. The chorus still slams in because nothing walks up to it. ClimbFour loads FluidR3_GM chairs (grand piano, nylon guitar, acoustic bass, string ensemble) and plays a four-bar climb in the key you pick.

## Distinct from the rest of the morning desk family

| Desk | Job |
| --- | --- |
| FadeEight | Last chorus walks *off* |
| AmenFour | Last line twice and sit |
| SeamFour | Loop bar 8 turns home |
| VerseEight / FromHook | Write the verse in front of a hook |
| DoorTwo | Section *entry* |
| **ClimbFour** | Four bars *into* the hook |

## Use

1. Open the site.
2. Arm FluidR3 chairs (FluidR3_GM soundfont).
3. Pick key, mode, BPM, recipe.
4. Play the four-bar climb under the last line of the verse.
5. Drop the hook.
